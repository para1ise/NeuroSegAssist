# NeuroSegAssist

**NeuroSeg Assist** — сервис автоматической 3D-сегментации опухолей головного мозга по МРТ с агентом-ассистентом радиолога. Проект создается с оглядкой на требования «Московского эксперимента» (MosMed).

## О проекте

- **Бизнес-цель:** Сократить время врача на рутинные измерения (обводка, расчет объемов и размеров) и написание протокола.
- **Ядро (CV):** 3D-сегментация глиом (BraTS) на базе архитектуры SegResNet. На входе — МРТ (FLAIR, T1ce), на выходе — маски субрегионов (WT, TC, ET), 2 размера и объем.
- **LLM-ассистент (NLP):** Self-hosted LLM формирует черновик заключения. Строгий code-based валидатор гарантирует, что LLM не выдумывает цифры (галлюцинации блокируются, при ошибке отдается Jinja-шаблон).

## Разработка и запуск

В проекте настроены линтеры и форматеры (Ruff). Для установки pre-commit хуков выполните:

```bash
pip install pre-commit ruff
pre-commit install
```
